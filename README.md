# Spritz

Lecteur de livres EPUB en lecture rapide (RSVP) : les mots s'affichent un par un, au même endroit, avec une lettre repère en rouge pour fixer le regard.

## Fonctionnalités
- Import de livres EPUB sans DRM, ou texte collé
- Navigation par chapitre, progression et temps restant
- Vitesse réglable de 150 à 800 mots par minute, pauses automatiques sur la ponctuation
- Tap pour lire ou mettre en pause, glisser vers la gauche pour revenir d'une phrase
- Fonctionne hors ligne une fois installée ; les livres restent stockés dans le navigateur de chaque appareil

## Mise à jour
Après avoir modifié un fichier, change la version dans `sw.js` (`spritz-v1` → `spritz-v2`) pour que les appareils récupèrent la nouvelle version.
